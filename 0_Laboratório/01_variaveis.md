# Variáveis

## O que é?

Uma variável é um nome que referencia um valor.

## Onde uso?

Guardar informações para reutilizar durante o programa.

## Exemplo

nome = "Leonardo"

print(nome)


campanhas = ["Rede de Pesquisa", "Google Shopping"]

campanhas.append("YouTube")           # adiciona no final
campanhas.insert(1, "Rede de Display") # insere numa posição específica
campanhas.remove("Google Shopping")   # remove pelo nome/conteúdo
campanhas.sort()                       # ordena (alfabética, ou numérica se for números)
